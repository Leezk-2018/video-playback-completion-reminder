# 课程播放助手

一个无需构建的 Chrome Manifest V3 扩展，用于管理课程目录播放、保持网页视频持续播放、跟踪学习进度，并在视频完播时发送提醒。适合网课、课程平台和其他使用 HTML5 video 的网页。

## 功能概览

- 自动识别当前页面及可访问 iframe 中的 HTML5 视频。
- 读取课程目录并展示课时标题、层级、当前播放项和已播放数量。
- 目录解析结果按标签页缓存；页面导航后自动失效，可点击“解析”手动刷新。
- 点击目录课时即可切换视频并尝试开始播放。
- 播放倍速支持输入 `0.1x–16x`，默认 `1x`。
- 连续播放：当前视频结束后自动切换并播放下一个课时。
- 跳过已看：连续播放时跳过目录中已学完的视频。
- 持续播放：开始监测后，当前页面视频被暂停时会自动恢复，包括前台、后台和用户手动暂停。
- 提醒方式可独立选择系统提醒、QQ 邮箱提醒，也可以同时开启或全部关闭。
- QQ 邮件内容包含完播课时、目录进度、剩余视频数量、页面标题、链接和完成时间等统计信息。
- 面板底部提供作者信息、GitHub 项目链接、反馈邮箱复制和微信收款码。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目根目录。

## 使用

1. 打开包含视频或课程目录的 HTTP/HTTPS 页面。
2. 点击浏览器工具栏中的扩展图标。扩展会优先读取当前页面已加载的目录，并在页面导航后重新解析。
3. 在“页面目录”中查看课时进度，点击任意课时可切换播放；需要重新识别时点击“解析”。
4. 在“提醒偏好设置”中输入播放倍速，并按需开启连续播放和跳过已看。
5. 选择一种或多种提醒方式，点击“开始监测”。监测期间可点击“停止监测”结束当前页面会话。

开始监测后，扩展会尝试恢复当前页面视频的任何暂停，包括页面切到后台、窗口最小化和用户手动暂停。视频结束或接近结尾时不会恢复，以便连续播放正常切换。若网站或浏览器策略禁止播放，仍可能无法恢复。

播放倍速和监测状态只在当前页面会话有效；刷新、跳转、关闭标签页或停止监测后会结束。循环视频不会触发 `ended` 事件；不暴露 HTML5 `video` 元素的播放器无法被监测。

## QQ 邮箱提醒配置

QQ 邮箱需要使用“授权码”，不能使用 QQ 登录密码。授权码由 QQ 邮箱生成，仅用于本机 SMTP 桥接服务发信。

1. 在 QQ 邮箱网页中进入“设置 → 账户”，开启 `SMTP/IMAP` 服务并生成授权码。
2. 在项目目录的 PowerShell 中运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\start-qq-mail-bridge.ps1
   ```

3. 按提示输入发件 QQ 邮箱和授权码，并复制窗口显示的桥接服务连接密钥。
4. 在扩展面板选择“邮件提醒”或同时选择“系统提醒 + 邮件提醒”，填入收件人邮箱和连接密钥，点击“保存设置”。
5. 点击“发送测试邮件”确认配置成功。

桥接服务只监听本机 `127.0.0.1:8787`。授权码不会写入扩展或磁盘；关闭 PowerShell 窗口后邮件提醒会停止。若只使用系统提醒，无需启动桥接服务。

## 隐私与权限

扩展仅在用户打开的 HTTP/HTTPS 页面中读取视频和目录信息，用于本地播放控制与进度展示。目录缓存保存在当前浏览器会话中，页面导航后清除。邮件发送通过本机桥接服务完成，扩展不会将 QQ 授权码上传到第三方服务器。
