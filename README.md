# 视频播放完成提醒

一个无构建步骤的 Chrome Manifest V3 扩展。它可以监测当前网页及可访问 iframe 内的 HTML5 视频，控制播放倍速，并在视频结束时发送系统通知或 QQ 邮箱提醒。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目根目录。

## 使用

1. 打开包含视频的普通 HTTP 或 HTTPS 网页。
2. 点击浏览器工具栏中的扩展图标，选择所需播放倍速和提醒类型，然后选择“开始监测”。
3. 视频自然播放结束时，会按所选提醒类型发送通知。

播放倍速与监测只在当前页面会话有效。刷新、跳转、关闭标签页或点击“停止监测”后会停止。循环视频不会触发 `ended` 事件；不暴露 HTML5 `video` 元素的播放器也无法被监测。

## QQ 邮箱提醒配置

QQ 邮箱需要使用“授权码”，不能使用 QQ 登录密码。授权码由 QQ 邮箱生成，只用于 SMTP 发信。

1. 在 QQ 邮箱网页中进入“设置 → 账户”，开启 `SMTP/IMAP` 服务并生成授权码。
2. 在 PowerShell 中运行项目里的 `start-qq-mail-bridge.ps1`。脚本会提示输入发件 QQ 邮箱和授权码，并显示一段连接密钥。
3. 保持脚本窗口运行，在扩展面板选择“QQ 邮箱提醒”或“系统通知 + QQ 邮箱”。
4. 将脚本显示的连接密钥填入“桥接服务连接密钥”，收件人填写 QQ 邮箱地址，点击“保存设置”。
5. 点击“发送测试邮件”确认配置成功。

桥接服务只监听本机 `127.0.0.1`，授权码不会写入扩展或磁盘；关闭 PowerShell 窗口后 QQ 邮箱提醒会停止。视频邮件会包含页面标题、链接和完成时间。
